# 🗄️ Projeto Banco de Dados MySQL

## 📌 Sobre o projeto

Este projeto tem como objetivo desenvolver e documentar um banco de dados utilizando MySQL, contemplando sua criação, estruturação, inserção de dados, consultas, atualizações e movimentações.

## 🛠️ Tecnologias utilizadas

- MySQL
- SQL
- Visual Studio Code
- Git e GitHub

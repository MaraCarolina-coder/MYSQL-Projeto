# 📚 Conceitos básicos de MySQL

## 1. O que é MySQL?

MySQL é um sistema de gerenciamento de banco de dados relacional utilizado para armazenar, organizar e consultar informações.

## 2. O que é SQL?

SQL significa Structured Query Language. É a linguagem utilizada para interagir com bancos de dados relacionais.

## 3. O que é banco de dados?

É um conjunto organizado de informações armazenadas eletronicamente.

## 4. O que é tabela?

É uma estrutura formada por linhas e colunas que organiza os dados.

## 5. O que é PRIMARY KEY?

É a chave primária responsável por identificar cada registro de forma única.

## 6. O que é FOREIGN KEY?

É a chave estrangeira que permite estabelecer relacionamentos entre tabelas.

## 7. O que é SELECT?

É o comando utilizado para consultar informações.

## 8. O que é INSERT?

É o comando utilizado para inserir informações.

## 9. O que é UPDATE?

É o comando utilizado para atualizar informações existentes.

## 10. O que é DELETE?

É o comando utilizado para excluir registros.

## 11. O que é JOIN?

É utilizado para combinar informações de tabelas relacionadas.

## 12. O que é TRANSACTION?

É um conjunto de operações que pode ser confirmado ou cancelado como uma unidade.

## 13. O que aprendi?

Com este projeto, pratiquei a criação de bancos de dados, criação de tabelas, relacionamentos, inserção de dados, consultas SQL e movimentações de estoque.
